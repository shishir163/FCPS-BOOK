FCPS Book (version 4.1)

Upload all files to your GitHub repository (keep the folders fonts/ and icons/) and replace the old ones.
The tools/ folder is only for reference and does not need to be uploaded.
Before you reload: close the app on your Mac and iPhone, and close any other open tab of it.
Then open the page and reload it twice, so the new version replaces the old one on your device.
Your existing questions, tags and settings stay as they are.

What is new in version 4
- Sort the systems: My order, A to Z, Most questions, Recently opened. It applies to the dashboard and the left menu.
- "Find a system" box in the left menu.
- Import questions from a file made from your documents (dashboard Import button, or Settings).
  See tools/IMPORT-FORMAT.md. Attach it with your documents when you ask Claude to prepare an import file.

- Shaded boxes and coloured left bars from imported documents are kept.

First install: MacBook (Safari) File > Add to Dock. iPhone (Safari) Share > Add to Home Screen.
Next update: change VERSION at the top of sw.js each time you upload new files.
Your notes are stored in the browser on each device. Use Settings > Export backup regularly.
