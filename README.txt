FCPS Book (Phase 1)

Put these files in a GitHub repository (keep the folders fonts/ and icons/), turn on GitHub Pages,
then open the page link. Install it:
  - MacBook (Safari): File > Add to Dock
  - iPhone (Safari): Share > Add to Home Screen

To update later: upload the new files and change VERSION at the top of sw.js so devices refresh.
Your notes are stored in the browser on each device. Use Settings > Export backup regularly.
