FCPS Book (version 2.1)

Upload all files to your GitHub repository (keep the folders fonts/ and icons/) and replace the old ones.
Then open the page and reload it twice, so the new version replaces the old one on your device.

What changed in 2.1
- New system list. On first open, empty starter systems from the old list are removed.
  A system that already has questions is never deleted.
- Dashboard text size: A- and A+ buttons on the dashboard, or a slider in Settings.
- More night themes: Midnight blue, Pure black, Charcoal, Warm night, Dusk violet.

First install: MacBook (Safari) File > Add to Dock. iPhone (Safari) Share > Add to Home Screen.
Next update: change VERSION at the top of sw.js each time you upload new files.
Your notes are stored in the browser on each device. Use Settings > Export backup regularly.
